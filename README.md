# GoBattle Ticket Values

A static, GitHub Pages-ready reference site for GoBattle relic and ultrarare ticket values.

## Included

- 46 item images from the supplied image archive
- Search by item name or category
- Category filters
- Separate Relics and Ultrarares sections
- Responsive layout for desktop and mobile
- No build step or external dependencies

## Upload to GitHub

1. Create or open the `GoogleUses/Gobattle-Ticket-Value` repository.
2. Upload the contents of this folder to the repository root. Make sure `index.html`, `styles.css`, `app.js`, and `assets/` are at the top level.
3. In GitHub, open **Settings → Pages**.
4. Set the source to **Deploy from a branch**, select the default branch and the `/ (root)` folder, then save.

The site will be served from `index.html`.
